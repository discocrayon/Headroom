# Version ceilings for boto3 and its stub packages.
#
# `boto3-stubs[...]` declares its per-service stubs as version ranges rather than
# pins, so a fresh install resolves each `mypy-boto3-*` package to its newest
# release. Some package indexes will not serve the very newest releases, and pip
# treats that refusal as fatal rather than falling back to an older version, so an
# unconstrained install can fail outright.
#
# A ceiling avoids that without having to know each package's version. The
# per-service packages are released independently, so their version numbers are
# sparse and do not line up: `mypy-boto3-organizations` has a 1.43.69 release
# while `mypy-boto3-ec2` does not, and the latter resolves to 1.43.67 under this
# ceiling. Each package picks its own newest release within the bound, and that
# choice is stable because every future release is above it.
#
# Raise these in step with the `boto3-stubs` pin in requirements.txt.
#
# tox.ini declares floors (`>=1.43.0`) rather than pins, so the umbrella packages
# float to the newest release and need ceilings here too. This has the side
# benefit of making a tox run resolve to the same versions requirements.txt pins.
boto3<=1.43.69
botocore<=1.43.69
boto3-stubs<=1.43.69
botocore-stubs<=1.43.69
mypy-boto3-ec2<=1.43.69
mypy-boto3-ecr<=1.43.69
mypy-boto3-eks<=1.43.69
mypy-boto3-iam<=1.43.69
mypy-boto3-kms<=1.43.69
mypy-boto3-lambda<=1.43.69
mypy-boto3-organizations<=1.43.69
mypy-boto3-rds<=1.43.69
mypy-boto3-s3<=1.43.69
mypy-boto3-secretsmanager<=1.43.69
mypy-boto3-sqs<=1.43.69
mypy-boto3-sts<=1.43.69

# Not boto3 packages, but subject to the same index refusal. Each is an
# unpinned dependency that floats to a release the index will not serve.
# Raise in step with upstream.
#
# `ast-serialize` is the one mypy itself pulls in, as `<1.0.0,>=0.6.0`. mypy is
# servable at its newest, so a ceiling on mypy would not have helped: every 2.x
# resolves that range to the same newest release. The ceiling belongs on the
# dependency that floats.
ast-serialize<=0.8.0
coverage<=7.15.4

platformdirs<=4.11.3
pydantic<=2.13.4
python-discovery<=1.5.2
